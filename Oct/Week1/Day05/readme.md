Python + LeetCode Practice 

My Learning Process

I first finished the Python video, which helped me understand functions, their syntax, loops, dictionaries, and other basics better.

After that, I moved to LeetCode to solve problems. For each problem, I followed this process:

1. Read the problem and tried to understand what it was asking.
2. Watched a YouTube explanation to understand the logic.
3. Wrote the logic down once in my own words before coding.
4. Coded the solution myself and added simple comments after each line to understand what I was doing.
5. Copied the code into VS Code and went through it again with GPT to understand each line more deeply.
6. Ran the sample inputs in VS Code to check if the output was correct.

The goal wasn’t just to get the correct answer, but to understand why the code works and get more comfortable writing Python on my own.

Problems Solved

1. Majority Element — LeetCode 169

Logic: Count how many times each number appears using a dictionary and keep track of the number with the highest frequency. The problem guarantees that a majority element exists.

2. Majority Element II — LeetCode 229

Logic: Find all numbers that appear more than n // 3 times. Use a counting and cancellation approach to narrow down the possible candidates, then check their actual frequencies.

3. Degree of an Array — LeetCode 697

Logic: Find the highest frequency of any number. Track the first and last positions of each number, then find the shortest subarray containing all occurrences of a number with that highest frequency.

4. Element Appearing More Than 25% in Sorted Array — LeetCode 1287

Logic: Since the array is sorted, repeated numbers appear next to each other. Check whether the same number appears again n // 4 positions later to find the element that occurs more than 25% of the time.
