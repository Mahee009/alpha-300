# Day 03 - Single Number

Single Number: XOR everything together, pairs cancel out (a ^ a = 0) and the lonely one is what's left. O(n), O(1) space.
Single Number II counts each of the 32 bits mod 3, Single Number III splits on the lowest set bit of a ^ b, Missing Number XORs indices with values, and Find the Difference XORs the ord() of every character.
